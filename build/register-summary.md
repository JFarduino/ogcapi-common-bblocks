# OGC API - Common Building Blocks

Building Blocks for OGC API - Common: the reusable schemas and OpenAPI components, together
with the requirements classes, clauses and annexes from which the standards documents are
generated. Currently Part 1: Core (OGC 19-072, version 1.0.0).


OGC API - Common is a multi-part standard that documents the set of common practices and
shared requirements that have emerged from the development of Resource Oriented Architectures
and Web APIs within the OGC. Standards developers will use these building-blocks in the
construction of other OGC Standards that relate to Web APIs. The result is a modular suite
of coherent API standards which can be adapted by a system designer for the unique requirements
of their system. As such, this OGC API Standard serves as the "OWS Common" standard for
resource-oriented OGC APIs.

This register brings together, with their full history, the technical and normative Building
Blocks of OGC API - Common that were previously in two repositories:

- ogcincubator/bblocks-ogcapi-common: Part 1 schemas, paths, responses and the API definition
- JFarduino/ogcapi-common-standards-as-bblocks: preface, clauses, requirements classes, annexes
  and test resources of [OGC API - Common - Part 1: Core](https://docs.ogc.org/is/19-072/19-072.html)
  (OGC 19-072), from which the standards document is generated by
  [bblocks-specgen](https://github.com/ogcincubator/bblocks-specgen) (see `standards.yaml`)


## Building Blocks

### `ogc.api.common.part1.annexes.ats` — Abstract Test Suite

**Type:** clause

Annex A of OGC API - Common - Part 1: Core: conformance classes and abstract tests. The tests are defined in the requirements classes (abstract-tests); this block lays out the annex.

### `ogc.api.common.part1.annexes.bibliography` — Bibliography

**Type:** references

Bibliography of OGC API - Common - Part 1: Core (informative references).

### `ogc.api.common.part1.annexes.bnf` — Backus-Naur Forms

**Type:** clause

Annex D of OGC API - Common - Part 1: Core: ABNF for URIs (from IETF RFC 3986).

### `ogc.api.common.part1.annexes.examples` — Examples (Informative)

**Type:** clause

Annex B of OGC API - Common - Part 1: Core: example landing pages, conformance declarations, API definitions and service metadata.

### `ogc.api.common.part1.annexes.glossary` — Glossary

**Type:** clause

Annex C of OGC API - Common - Part 1: Core: glossary of ModSpec terms.

### `ogc.api.common.part1.annexes.revision-history` — Revision History

**Type:** clause

Annex F of OGC API - Common - Part 1: Core: revision history.

### `ogc.api.common.part1.annexes.web-api-guidelines` — OGC Web API Guidelines

**Type:** clause

Annex E of OGC API - Common - Part 1: Core: how the Standard addresses the OGC Web API Guidelines.

### `ogc.api.common.part1.clauses.abbreviated-terms` — Abbreviated terms

**Type:** clause

Clause 5 of OGC API - Common - Part 1: Core: abbreviated terms.

### `ogc.api.common.part1.clauses.conformance` — Conformance

**Type:** clause

Clause 2 of OGC API - Common - Part 1: Core: conformance classes defined by the Standard and how conformance is tested.

### `ogc.api.common.part1.clauses.conventions` — Conventions

**Type:** clause

Clause 6 of OGC API - Common - Part 1: Core: Web API fundamentals, identifiers, links, link relations, use of HTTPS and API definitions.

### `ogc.api.common.part1.clauses.encodings` — Encoding Requirements Classes

**Type:** clause

Clause 10 of OGC API - Common - Part 1: Core: overview of the HTML and JSON encoding requirements classes, which are its subclauses 10.2 and 10.3.

### `ogc.api.common.part1.clauses.media-types` — Media Types

**Type:** clause

Clause 12 of OGC API - Common - Part 1: Core: media types for responses, OpenAPI definitions and Problem Details reports.

### `ogc.api.common.part1.clauses.overview` — Overview

**Type:** clause

Clause 7 of OGC API - Common - Part 1: Core: evolution from OGC Web Services, modular APIs and the ways clients use OGC APIs.

### `ogc.api.common.part1.clauses.references` — Normative references

**Type:** references

Clause 3 of OGC API - Common - Part 1: Core: normative references (the informative ones are in the Bibliography).

### `ogc.api.common.part1.clauses.scope` — Scope

**Type:** clause

Clause 1 of OGC API - Common - Part 1: Core: the scope of the Standard.

### `ogc.api.common.part1.clauses.terms` — Terms and definitions

**Type:** terms

Clause 4 of OGC API - Common - Part 1: Core: terms and definitions.

### `ogc.api.common.part1.preface.preface` — Preface

**Type:** clause

Preface of OGC API - Common - Part 1: Core (preface section).

### `ogc.api.common.part1.preface.security-considerations` — Security considerations

**Type:** clause

Security considerations of OGC API - Common - Part 1: Core (preface section).

### `ogc.api.common.part1.preface.submitters` — Submitters

**Type:** clause

Submitters of OGC API - Common - Part 1: Core (preface section).

### `ogc.api.common.part1.preface.submitting-organizations` — Submitting Organizations

**Type:** clause

Submitting Organizations of OGC API - Common - Part 1: Core (preface section).

### `ogc.api.common.part1.schemas.queryParamValueBoolean` — Boolean query parameter value

**Type:** datatype

The encoding of a boolean query parameter value: the lowercase strings "true" and "false".

### `ogc.api.common.part1.schemas.queryParamValueDecimal` — Decimal query parameter value

**Type:** datatype

The encoding of a decimal query parameter value: decimal digits separated by a period as a decimal indicator.

### `ogc.api.common.part1.schemas.queryParamValueDouble` — Double query parameter value

**Type:** datatype

The encoding of a double (exponential-format) query parameter value: a decimal mantissa followed, optionally, by an integer exponent.

### `ogc.api.common.part1.schemas.queryParamValueInteger` — Integer query parameter value

**Type:** datatype

The encoding of an integer query parameter value: a finite-length sequence of decimal digits with an optional leading negative sign.

### `ogc.api.common.part1.schemas.queryParamValueList` — Delimited list query parameter value

**Type:** datatype

The encoding of a query parameter value that is a delimited list of values, one of the two ways OGC API - Common allows passing more than one value for a parameter.

### `ogc.api.common.part1.schemas.confClasses` — Conformance Classes schema

**Type:** schema

This building block corresponds to the schema for an OGC API Common confClasses

### `ogc.api.common.part1.schemas.exception` — Exception schema

**Type:** schema

This building block corresponds to the schema for an OGC API Common exception

### `ogc.api.common.part1.schemas.link` — Link schema

**Type:** schema

This building block corresponds to the schema for an OGC API Common link

### `ogc.api.common.part1.requirements.core` — Core Requirements Class

**Type:** requirements-class

Requirements class "Core": protocol-level conventions applicable to all OGC Web APIs - use of HTTP 1.1, HTTP status codes, query parameter names and values, web caching, cross-origin requests, string internationalization, resource encodings and parameter encoding.

### `ogc.api.common.part1.responses.ConformanceDeclaration` — ConformanceDeclaration response

**Type:** response

The response for the OGC API conformance declaration resource.

### `ogc.api.common.part1.responses.Exception` — Exception response

**Type:** response

An RFC 7807 "Problem Details" error response, as recommended by OGC API - Common for any error situation.

### `ogc.api.common.part1.schemas.landingPage` — Landing Page schema

**Type:** schema

This building block corresponds to the schema for an OGC API Common landingPage

### `ogc.api.common.part1.paths.Conformance` — Conformance path

**Type:** path

The conformance declaration ("{root}/conformance"), listing the conformance classes implemented by this API.

### `ogc.api.common.part1.responses.LandingPage` — LandingPage response

**Type:** response

The response for the OGC API landing page resource.

### `ogc.api.common.part1.paths.LandingPage` — LandingPage path

**Type:** path

The OGC API landing page ("{root}/"), the single starting point for discovering the resources exposed by the API.

### `ogc.api.common.part1.api` — OGC API - Common

**Type:** api

OGC API - Common OpenAPI-based building block, combining the landing page, conformance declaration and API definition resources into a single OpenAPI document.

### `ogc.api.common.part1.requirements.landing-page` — Landing Page Requirements Class

**Type:** requirements-class

Requirements class "Landing Page": the landing page, the API definition and the conformance declaration resources of an OGC Web API.

### `ogc.api.common.part1.requirements.html` — Requirements Class “HTML”

**Type:** requirements-class

Encoding requirements class "HTML": HTML 5 representations of the Landing Page and Conformance resources.

### `ogc.api.common.part1.requirements.json` — Requirements Class “JSON”

**Type:** requirements-class

Encoding requirements class "JSON": JSON representations of the Landing Page and Conformance resources. The schema of this building block is the JSON payload of these resources, so that the test resources of the class are validated against it.

### `ogc.api.common.part1.requirements.oas30` — OpenAPI 3.0 Requirements Class

**Type:** requirements-class

Requirements class "OpenAPI 3.0": requirements for APIs that are self-documented using an OpenAPI 3.0 definition.
